# Установка «Смены» на Android

## Что это

Личное приложение для учёта смен, часов и зарплаты. Работает офлайн, всё хранится на телефоне.
Ничего никуда не отправляет: ни аккаунта, ни сервера, ни регистрации.

## Способ 1: APK с сайта

1. Открой сайт, нажми **«Скачать APK»**.
2. Введи код приглашения (выдаёт автор) — он запомнится на устройстве.
3. Скачается файл `farfor-shifts.apk` (≈24 МБ).
4. Открой его из «Файлов» или «Браузера» и разреши установку из этого источника.
5. При первом запуске спросит имя и PIN-код 4–6 цифр. Второй раз — для подтверждения.

> Если Android ругается «установка запрещена» — зайди в **Настройки → Приложения → Специальный
> доступ → Установка неизвестных приложений** и разреши своему браузеру или файловому менеджеру.

## Способ 2: PWA в браузере

Открой сайт на телефоне → «Добавить на главный экран». Работает как обычное приложение,
но без доступа к файловой системе и без .ics-экспорта в некоторых браузерах.

## При обновлении

Если при установке новой версии Android пишет, что приложение «уже установлено с другим
подписью» — старую версию надо сначала удалить:

**Настройки → Приложения → Смена → Удалить**.

Данные лежат в памяти приложения, поэтому перед удалением сделай экспорт:
**Ещё → Данные → Экспорт JSON** (файл можно сохранить и потом загрузить обратно).

## Частые вопросы

**Забыл PIN.** На экране входа есть «Забыл код» — сбрасывается только код и имя.
Смены, часы и деньги остаются на месте.

**Смена не засчитали.** Открой день в календаре и впиши фактические часы — сумма пересчитается.
Так же добавь «Списание» в Табеле, если что-то удержали.

**Хочу считать по другому.** Всё настраивается в **Ещё → Профиль**: ставка, часы смены,
даты аванса и зарплаты, процент аванса (40% от первых 20 дней), размер окна, напарник.

**Как посчитать план на месяц?** **Ещё → Расчёты**: за месяц, за год, за отпуск,
сколько часов на 10 000 ₽.

**Как передать табель шефу?** **Ещё → Поделиться отчётом** — текст в буфер или в мессенджер.
**Ещё → Ссылка на график** — ссылка, по которой открывается твой месяц с графиком.

**Как выгрузить в календарь телефона?** **Ещё → Календарь (.ics)** — файл импортируется
в календарь Android/Google Calendar со временем смены.

## Требования

- Android 7.0 (API 24) и новее
- ~24 МБ свободного места
- интернет не нужен (после установки)

## Сборка из исходников

```bash
git clone https://github.com/moovivan7-art/farfor-shifts
cd farfor-shifts
bash tools/build_apk.sh
```

Нужны JDK 17, Android SDK 34 и Gradle 8.7. Подробности — в [README.md](README.md).
