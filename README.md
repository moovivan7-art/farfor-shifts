# Смена

## Зачем

Сотрудник сменного ресторана в конце месяца знает две вещи: сколько он отработал и сколько ему
должны. Всё остальное — «где-то у бухгалтера», «в приложении точки», «на бумажке». Если вечером
ушёл раньше, если забыли открыть смену, если прилетел штраф — это нигде не учитывается и уходит
из зарплаты тихо.

**«Смена»** — персональный учёт смен, часов и выплат. Без аккаунта, без сервера, без регистрации:
всё лежит в памяти телефона. Ставится за десять секунд, весит 24 МБ, работает офлайн.

## Что внутри

| Фича | Зачем |
|---|---|
| **Свой цикл графика** | Любой ритм: `1/1`, `2/2`, `3/3`, `2/2,3/3`, лесенка `1/1,2/2,3/3` — считается и смена, и зарплата |
| **Окон в день (2–3)** | Двойная смена: два окна в сутки, у каждого свои часы, ставка и сумма |
| **Аванс и зарплата** | Аванс 1-го, зарплата 15-го. Сразу видно, сколько придёт к каждой выплате |
| **Правило 40%** | Из заработка за первые 20 дней 40% уходит в аванс, остальное — в премию. Разбивка видна сразу |
| **Доплаты списком** | +10 за план, +10 за скорость, чаевые, премия — всё складывается в одну сумму |
| **Списания и штрафы** | Прилетел штраф — запиши. Видно, сколько заработал и сколько забрали |
| **Напарник вдвоём** | Смену делите с коллегой: у каждого свои часы и свои деньги, общая сумма точки тоже видна |
| **Копии** | Отметил смену — раскинул на две недели вперёд. Месяц копируется в следующий целиком |
| **Ссылка на график** | Скинул ссылку шефу — он видит твой месяц. Или отчёт текстом в мессенджер |
| **Календарь `.ics`** | Выгрузка смен в календарь телефона — со временем и точкой |
| **Праздники РФ** | Производственный календарь на 2026: праздники и предпраздничные на час короче |
| **Вход по коду** | 4–6 цифр. Забыл — смены и деньги остаются на месте, стирается только код |
| **Статистика** | Заработок по дням, факт против графика, лучшая смена, серия смен, награды |

## Как считаются деньги

```
смена   = часы × ставка
месяц   = сумма смен + доплаты − списания
аванс   = 40% от заработка за первые 20 дней
премия  = 60% от первых 20 дней + остаток месяца + доплаты
```

Пример на ставке 275 ₽/час и смене 13 ч 45 мин: 10 смен за первые 20 дней = **37 813 ₽**,
в аванс уходит **15 125 ₽**, в премию — **22 688 ₽**. Процент, размер окна, даты выплат и ставка
меняются в настройках.

Часы считаются дробно: `parseFloat` обязателен, `parseInt` срезает минуты.

## Сайт

В папке [`site/`](site/) — лендинг для сотрудников: чёрно-оранжевое стекло, анимированные GIF
с живым интерфейсом, конструктор графика прямо в браузере и скачивание APK по коду приглашения.
Сайт сделан статикой: бэкенда нет, доступ — по хэшам кодов в `site/config.js`.

```bash
cd site && python3 -m http.server 8080   # любой статический сервер
```

## Сборка из исходников

Приложение — чистый HTML/CSS/JS без зависимостей, сборка веб-части не нужна.
APK собирается стандартным Android-тулчейном.

```bash
# 1. JDK 17, Android SDK 34, Gradle 8.7
export ANDROID_HOME=/path/to/android-sdk
export JAVA_HOME=/path/to/jdk-17

# 2. ключ подписи (в репозиторий не попадает)
keytool -genkeypair -v -keystore farfor.keystore -alias farfor \
  -keyalg RSA -keysize 2048 -validity 10000
cat > android/keystore.properties <<EOF
storeFile=/path/to/farfor.keystore
storePassword=...
keyAlias=farfor
keyPassword=...
EOF

# 3. собрать
bash tools/build_apk.sh
```

Или вручную:

```bash
cd android && gradle assembleRelease
```

## Тесты

Проверка в настоящем браузере (Playwright + Chromium) — приложение и сайт:

```bash
python3 test/e2e.py        # 28 проверок: заставка, вкладки, цикл, окна, доплаты, 40%, напарник, копии, .ics
python3 test/site_e2e.py   # сайт: конструктор, код доступа, мобильная версия, скриншоты
```

Тесты ловят реальные баги: например, цикл `1/1,2/2,3/3` считался неправильно из-за отрицательного
остатка в алгоритме, а версия 1.3.1 вечно держала заставку — это нашли только на телефоне.

